# HTTP Request Analysis

## Objective

The objective of this lab is to understand the structure of HTTP requests and responses by analyzing real network traffic generated by OWASP Juice Shop using Burp Suite. This lab focuses on identifying the different components of an HTTP request and understanding how browsers communicate with web applications.

---

## Introduction

Every interaction between a browser and a web application is performed using the HTTP protocol. Understanding HTTP requests and responses is a fundamental skill for Application Security Engineers because almost every web vulnerability can be identified by analyzing network traffic.

In this lab, Burp Suite will be used to capture and inspect HTTP requests sent from Mozilla Firefox to OWASP Juice Shop.

## Prerequisites

Before starting this lab:

* Docker is running.
* OWASP Juice Shop is accessible.
* Burp Suite is configured as the browser proxy.
* HTTP traffic can be captured successfully.

---

## Topics Covered

* HTTP Methods (GET, POST)
* URL Structure
* HTTP Headers
* Request Body
* Response Headers
* Status Codes
* Cookies
* Session Management

---

## Lab Tasks

* Open OWASP Juice Shop.
* Navigate to the Login page.
* Submit a test login request.
* Capture the request using Burp Suite.
* Identify the HTTP method.
* Analyze request headers.
* Examine the request body.
* Observe the server response.
* Understand how authentication requests are transmitted.

---

## Expected Learning Outcomes

After completing this lab, I will be able to:

* Explain the structure of an HTTP request.
* Differentiate between GET and POST requests.
* Identify common HTTP headers.
* Understand the purpose of cookies and sessions.
* Analyze requests using Burp Suite.
* Build a foundation for testing vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), and Broken Access Control.
