# OWASP Juice Shop Security Lab

## Overview

This project documents my hands-on learning using the OWASP Juice Shop application.

The goal of this lab is to understand common web application vulnerabilities, how to identify them safely in a lab environment, and how they can be prevented.

## Environment

- Kali Linux (Virtual Machine)
- OWASP Juice Shop
- Burp Suite Community Edition
- Firefox Browser

## Learning Objectives

- Understand HTTP requests and responses
- Learn how Burp Suite intercepts traffic
- Practice identifying common web vulnerabilities
- Learn secure coding concepts
- Improve web application security knowledge

## Lab Sections

1. Lab Setup
2. Burp Suite Proxy
3. HTTP Request Analysis
4. SQL Injection
5. Cross-Site Scripting (XSS)
6. Access Control
7. Screenshots

> This repository documents my learning process and does not contain challenge answers or exploit walkthroughs.
