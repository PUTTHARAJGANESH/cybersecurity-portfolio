# Networking Basics Lab

## Objective

Learn the fundamentals of computer networking and basic device communication.

## Topics Learned

- What is a Network
- LAN
- WAN
- Switch
- Router
- IP Address
- MAC Address
- OSI Model

## Practical Work

Using Cisco Packet Tracer:

- Connected 3 PCs to a switch
- Assigned IP addresses
- Verified connectivity between devices

## Skills Gained

- Basic network setup
- Understanding of network devices
- IP addressing fundamentals
- Packet flow basics

## Tools Used

- Cisco Packet Tracer

## Outcome

Successfully created a basic LAN and established communication between devices.
